## Changelog:

### 1.0.2:
* **Bug Fixes**:
  1. Fixed an issue where deleting a response item in Settings did not show a confirmation prompt.
  2. Fixed an issue where editing a response item in Settings created an extra item.

### 1.0.1:
* **Added settings interface**: Provides a configuration page for changing the port and customizing responses.
* **Added port modification feature**: When a port is already in use, a prompt will appear asking whether to change the port.
* **Added custom response feature**: When a request matches the specified path and HTTP method, the configured response content will be returned to the client.
